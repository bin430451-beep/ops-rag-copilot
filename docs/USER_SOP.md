# 用户使用 SOP
## 一、登录与访问
1. 仅内网可访问 `http://<平台域名>:8080`
2. 首次使用需向管理员申请 `X-API-Key`
3. 浏览器访问首页，在顶部输入框填入 API Key
## 二、知识库问答
1. 在输入框描述问题，尽量包含**系统名 + 现象 + 报错关键字**
2. 点击「提问」，等待 5–30 秒
3. 若答案下方出现「降级」提示，说明大模型不可用，请参考返回的原文片段
### 提问建议
- ✅ "Nginx 返回 502，上游是 Java 服务，如何排查？"
- ✅ "Oracle 表空间满的应急处理步骤"
- ❌ "怎么修"（缺少上下文）
## 三、文档上传（有权限用户）
1. 调用 `/api/v1/kb/upload`
2. 上传后需管理员审核（`/documents/{doc_id}/approve`）
3. 支持格式：PDF / DOCX / Markdown / TXT
### 文档规范
- 标题使用 Markdown `##` 分级，切分效果更好
- 单文件建议 ≤ 50 MB
- 敏感文档请设置 `dept` 字段以隔离检索范围
## 四、告警分析
监控系统触发告警后，自动调用 `/ops/analyze-alert`，返回结构：
```
【现象】...
【可能原因】...
【建议操作】...
【是否需要升级】...
```
请 SRE 结合实际情况判断，AI 输出不替代人工决策。
